Setup in 5 steps

1

Unzip it

Put it somewhere easy to find, like your Desktop. You'll get a folder called toon-explainer-kit-main.

2

Install the two tools it needs

Skip any you already have: Node.js 18+ and ffmpeg. No Python needed.

WINDOWS (POWERSHELL)winget install OpenJS.NodeJS.LTS; winget install Gyan.FFmpeg
MACbrew install node ffmpeg
3

Run setup once

On Windows, double-click setup.bat inside the folder. On Mac or Linux, run the command below inside the folder. It installs the renderer (~200 MB) and does a test render.

MAC / LINUXbash setup.sh
4

Open the folder in Claude Code and say what you want

Claude reads the kit's rules and walks you through it: angle, script for your OK, storyboard preview, voice, render, then a style check.

SAY THIS TO CLAUDEmake a video about why the stock market crashed
5

Have your ElevenLabs key ready

For the voiceover, or record your own and give Claude the file. Optional: an OpenAI or fal key for AI-painted backgrounds. Your finished video lands in projects/<name>/out/final.mp4.
